# 法学与人文社科论文写作指南

> 面向中文法学与人文社科研究的写作 Skill，帮助梳理论文结构、检查论证与引文、调整语言，并完成成熟稿的定点修订。

材料整理了不少，提纲里的几个章节却总在回答同一个问题？

文字读起来很顺，但概念、证据和结论之间仍有跳跃？

论文已经改了多轮，再交给 AI 润色，又被改回统一的句式和段落模板？

本项目将论文写作与审校要求整理为 **12 个模块、144 条规则**，让 AI 按照明确的研究任务、证据要求和修改范围协助工作。适用于博士论文、学术期刊论文、文献综述、研究提纲及基金申请等正式学术文本。

## 设计初衷

论文修改中，许多问题发生在单句之外：章节之间缺少分工，同一案例反复证明同一结论，文献确实存在却没有支持正文中的具体判断。只做语言润色，往往无法发现这些问题。

这个 Skill 将修改顺序落实到具体工作：先确定研究对象和章节任务，再检查段落推进、判断层次与证据，最后处理措辞、引注和格式。每一处修改都需要说明它解决了什么问题。

对于已经经过作者多轮修改的稿件，保留准确、自然的表达。只需要调整脚注，就集中处理脚注；需要检查论证，就先指出问题和依据。发现范围之外的事项，另列建议，避免成熟文本在反复润色中失去原有思路。

## 使用示例

安装后，可以根据当前任务直接提出要求。以下为示例提示词。

### 梳理提纲与章节分工

```text
请使用本 Skill 检查这份论文提纲。
先说明每章、每节分别回答什么问题，再找出重复、缺口和逻辑跳跃。
调整标题与顺序，但不要为了结构整齐而强行凑出相同数量的小节。
```

### 修改正文并保留作者表达

```text
这是我已经多轮修改的论文正文。
请检查相邻段落的推进关系、概念使用及重复论证。
准确且自然的文字保留，只作必要修改。
新增或替换内容加下划线，删除内容单独说明。
```

### 核对引文与证据

```text
请对照所附文献原文，检查脚注是否支持正文中的具体命题。
分别核对来源、版本、页码或段落，以及结论的适用范围。
将结果标为已核实、待核实或存在疑问，不补造缺失信息。
```

### 整理比较法分析

```text
请先梳理各法域的规则、判例和未决争议，
再围绕共同法律问题组织横向比较。
保留制度差异，说明哪些概念不能直接对应，以及借鉴需要满足的条件。
```

## 功能模块

以下是同一个 Skill 内部的规则模块，按任务选用，无需分别安装。

| 模块 | 处理什么问题 |
| --- | --- |
| 工作边界 | 确定最新母稿、稿件阶段和修改范围，保留成熟表达 |
| 证据核查 | 检查来源、引证位置与正文命题的对应关系 |
| 概念与判断 | 区分研究对象、成立条件、适用限制和法律后果 |
| 结构与标题 | 明确章节目分工，使标题准确覆盖正文 |
| 段落推进 | 检查相邻段落为何衔接，减少材料并列和模板化展开 |
| 文献与裁判 | 按问题组织综述，区分裁判理由、学者观点与作者评价 |
| 比较法研究 | 先解释各法域，再围绕共同争点比较规则与制度条件 |
| 历史分析 | 结合时间与问题变化，避免用现代概念倒推历史 |
| 语言与术语 | 保持术语稳定，减少空泛概括、固定转折和无依据的强调 |
| 重复论证 | 以命题为单位查重，检查案例和文献再次出现的新增作用 |
| 著作权专题 | 处理作品识别、功能限制、可分离性及保护范围等相关问题 |
| 修订与交付 | 核对修改差异、真实Word脚注、文档结构与版面 |

著作权专题仅在研究主题相关时启用，不作为其他法学或人文社科论文的固定分析框架。

## 开始使用

1. 下载并解压技能包，保留 `chinese-law-humanities-writing` 文件夹中的文件及相对位置。
2. 按所用 AI 工具的技能安装方式，导入或放置整个技能目录。只上传到 GitHub，不会自动完成安装。
3. 提供待处理的提纲、正文或材料，并说明目标、修改范围及学校或期刊的格式要求。
4. 使用中文名称调用本 Skill；支持 `$技能标识` 的客户端，也可以使用 `$chinese-law-humanities-writing`。

建议先用一节正文试用，确认修改幅度与表达方式，再扩展到整章或全文。

### 使用条件

- **引文核实需要原文。** 只有题名、链接或检索结果时，不能据此认定具体页码和正文命题已经核实。
- **文档处理依赖运行环境。** Skill 提供规则和流程，不自带检索数据库、Word编辑器或渲染程序。相关检查需要所在环境具备对应工具。
- **未完成的检查应当说明。** 没有取得原文或无法查看渲染结果时，保留待核事项，不报告为全部通过。

本项目辅助研究与审校，论文的学术判断和最终定稿仍需作者确认。
